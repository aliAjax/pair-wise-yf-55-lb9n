# pair-wise-yf-55 动态表单规则编排和版本迁移模拟器

## 源提示词摘要
业务人员拖拽字段、设置分组、联动条件、计算规则、必填逻辑和多语言文案；发布前模拟旧数据在新结构下的迁移。系统比较版本差异，警告失效规则、循环依赖和引用删除，同时按历史版本解释过去提交的数据。

## 技术栈
React 19 + TypeScript + Vite + MUI + Redux Toolkit + RTK Query + React Router + React Hook Form + Zod + i18next + dnd-kit。

## 已实现闭环
- 表单版本、字段、联动规则和旧数据快照等业务对象。
- 字段拖拽排序、新增字段、添加联动规则、发布新版本。
- 新旧版本差异、旧数据迁移缺口模拟。
- 运行态动态表单、跨字段校验和历史版本解释。
- localStorage 持久化。

## 对账口径管理（/recon）
平台统一维护供应商对账单的字段口径，外部系统照着生效口径推送数据。

- 口径版本化：草稿编辑字段（名称/类型/必填），发布后成为新生效口径。
- 发布前影响面预检：列出相对最新基线的口径差异和受影响的在途批次，定稿批次明确排除。
- 发布即失效：在途对账批立即失效，生成重算任务按新口径重新校验；定稿结果保持原样。
- 推送时口径冻结：已收到的数据仍按推送当时的口径版本解释。
- 分批重算：超出容量自动分批，失败从断点重试，进度持久化，重开页面可继续。
- 并发提交：两名运营同时提交同一份口径时，后到的按最新基线重算影响面并保留为草稿。
